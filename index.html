Sinkronisasi Cloud

Simpan data otomatis & selaras di semua perangkat (Firebase Realtime Database)

Tidak terhubung ke cloud

Cara mengaktifkan (sekali saja):
1. Salin objek firebaseConfig dari Project Settings → Your apps → Web di console.firebase.google.com.
2. Tempel nilainya ke objek FIREBASE_CONFIG di file firebase.js.
3. Menu Build → Realtime Database → ganti Rules dengan:
{  "rules": {   "users": {    "$uid": {     ".read": "$uid === auth.uid",     ".write": "$uid === auth.uid"    }   }  } } 4. Menu Build → Authentication → Sign-in method → aktifkan Google.
5. Muat ulang halaman, lalu klik Masuk dengan Google.
6. Pakai akun Google yang sama di semua perangkat agar data otomatis tersinkron.
Catatan: login Google memerlukan HTTPS atau localhost (bukan file://). Gunakan VS Code Live Server, GitHub Pages, atau Netlify.
